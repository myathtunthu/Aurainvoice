# AURA ENERGY MYANMAR — Invoice & Receipt Document Center

Mobile-first React + Vite web app for creating AURA Energy Myanmar Sale Invoices and Receipts without Excel.

## Features
- Sale Invoice template based on supplied AURA invoice PDF.
- Receipt template based on supplied AURA receipt PDF.
- Mobile-first form.
- Product presets for current AURA catalog.
- Automatic line amount, total, advance/balance and receipt amount in words.
- Local browser history via localStorage.
- Export to PDF and PNG using html2canvas + jsPDF.
- Print support.

npm install
npm run build
